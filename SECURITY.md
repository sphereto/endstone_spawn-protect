# Security Policy

## Supported versions

Only the latest release of endstone_spawnprotect receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/sphereto/endstone_spawn-protect/security/advisories/new),
or email **placeholder@example.com**.

Include what you found, how to reproduce it, the plugin version, and your Endstone
and Bedrock Dedicated Server versions. You can expect an acknowledgement within a
few days. Once a fix is released, the report is disclosed with credit to you unless
you prefer to stay anonymous.

## Scope

This policy covers the plugin's own code. Problems in Endstone itself or in Bedrock
Dedicated Server should be reported to their maintainers.
